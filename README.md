# PIXEL DJ · 像素打碟机

一个纯前端的网页打碟机。像素风梵高星空背景，支持双/三曲目混音。

## 使用

双击 `index.html` 用浏览器打开即可，无需安装任何东西。

> 建议用 Edge 或 Chrome。如需加载网页音频链接，请用本地服务器打开（双击打开会被浏览器跨域策略拦截）。

## 功能

- 导入本地 MP3 / WAV，或加载网页音频链接
- 双曲目 / 三曲目切换
- 效果器：延迟、混响、镶边、磨碎（各带 ON/OFF 开关）
- 速度 8 档：0.5× ~ 2.0×
- 每盘独立音量推子 + 主音量 + 交叉推子
- 梵高星空像素月亮转盘（播放时缓缓旋转）、星尘波形环、播放进度环、播放时流星划过

## 操作

| 操作 | 方式 |
|---|---|
| 调旋钮 | 鼠标上下拖动 |
| 旋钮复位 | 双击 |
| 旋钮微调 | 滚轮（Shift + 滚轮更细） |
| 开关效果器 | 点按钮名或 ON/OFF |
| 全部播放/暂停 | 空格键 |
| 导入音乐 | 点转盘 / 拖入文件 / 点「加载」 |

## 技术

单文件实现，使用 Web Audio API + Canvas，无任何依赖。
